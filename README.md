# Catch the Fish
A Mixed Reality interactive game where players catch different colored fishes projected in the environment. The game breaks the constraints of the screen and the pointer in 2 dimensions. It enables players to move in the real world to catch the fish, and their movement is tracked via HTC Vive Controllers, which are used as a scoop (net/handle to catch fish) in the game. The players are given a certain number of fishes and a specific order in which they have to catch them. Catching the correct fish allows players to advance in the game, while wrong ones cost them negative points (which we call "Tries").

A semester project for [Media Art & Design Project](https://www.hbksaar.de/studiengaenge/media-art-design) at [HBK Saar](https://www.hbksaar.de/).

## Environment Setup Requirements
- [HTC Vive Pro](https://www.vive.com)
- VIVE Ready Computer — [see this article](https://www.vive.com/de/vive-ready/)
- Vive, Steam & Steam VR Software Installed on Windows — [Complete Setup Guide](https://www.vive.com/eu/setup/vive-pro-hmd/)
- Two Top-Down Beamers (projectors)
- Projection area of 7.18m x 4.82~4.77m
- White floor sheet for better display
